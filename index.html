About EduTrack

Built with faculty, for the way classes actually run

EduTrack started as a request from a single computer science department that was still reconciling paper registers by hand. Three semesters later, it's the attendance system for the whole campus — because it was designed around real timetables, not a generic form.

  • Works across Admin, Teacher and Student roles out of the box
  • Firebase-backed, so data stays in sync across every device
  • Reports ready for accreditation audits in one click
